## 1. 目标

接通 backend (.40) → HPC (.53) 链路,FE `/api/md/*` 5 个真 endpoint 替换 `routes/stubs.py` 的 stub:
- `POST /api/md/submit` — 提 GROMACS MD 作业到 SLURM
- `GET /api/md/runs` — 列出本 user 近期 jobs
- `GET /api/md/jobs/{id}` — 拿单 job 状态
- `POST /api/md/jobs/{id}/cancel` — scancel + 标 cancelled
- `GET /api/md/gpu-pool` — 拉 `.53` 上 nvidia-smi 整理出 GPU 池占用

支持 3 种 simulation_type:**standard / smd_pulling / metadynamics**。

---

## 2. Scope 边界

### 在 MVP 内
- 5 个真 endpoint
- 3 个 sim_type sbatch 模板
- backend 后台 poll worker(30s scan + sacct 终态)
- GPU 池查询(`.53` 上 `check_gpus.sh` 脚本)
- ledger 完成时一次性扣费(GPU + CPU 溢额)
- 单 user 并发 ≤ 2

### 进 carry(v0.13.1 / 后续 milestone)
- umbrella / remd(需 parent_id + dispatch_strategy + 多 sbatch 协调)
- FE MdModal 表单扩展(smd pull 参数 / plumed file picker)
- artifacts 远程下载(SSH-cat 流)
- auto-retry on 429/preemption
- progress 估算精度(MVP 只 elapsed/expected ratio)
- per-replica trajectory storage(M10 storage 扩展)
- WHAM 后处理 / replex demux

## 4. 数据模型

### 4.1 PG 表:`md_jobs`(`migrations/versions/005_md_jobs.py`)

```sql
CREATE TABLE md_jobs (
    id            UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id       UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    sim_type      TEXT NOT NULL
                    CHECK (sim_type IN ('standard','smd_pulling','metadynamics')),
    params        JSONB NOT NULL,            -- 8 个 FE 字段 + structure_file_id + sim_params
    status        TEXT NOT NULL DEFAULT 'queued'
                    CHECK (status IN ('queued','running','done','failed','cancelled')),
    slurm_job_id  TEXT,                      -- sbatch 返回的 SLURM ID
    gpu_host      TEXT,                      -- 真跑的 GPU 节点
    progress      INTEGER NOT NULL DEFAULT 0 CHECK (progress BETWEEN 0 AND 100),
    error         TEXT,
    cost_li       BIGINT NOT NULL DEFAULT 0 CHECK (cost_li >= 0),
    cpu_hours     NUMERIC(10,3) NOT NULL DEFAULT 0,
    gpu_hours     NUMERIC(10,3) NOT NULL DEFAULT 0,
    created_at    TIMESTAMPTZ NOT NULL DEFAULT now(),
    started_at    TIMESTAMPTZ,
    finished_at   TIMESTAMPTZ
);

CREATE INDEX ix_md_jobs_user_created
  ON md_jobs(user_id, created_at DESC);

CREATE INDEX ix_md_jobs_active_status
  ON md_jobs(status)
  WHERE status IN ('queued','running');     -- backend poll worker 用
```

## 6. 关键流程

### 6.1 Submit 流程

```
FE POST /api/md/submit {structure: file_id, sim_type, ...}
│
1. handler 检 auth + concurrent < 2 + balance > 0
2. validate_sim_params(sim_type, sim_params) → 400 if 缺必填
3. MdJobRepo.create(...) → PG row status=queued
4. ssh_run("mkdir -p ~/praxis-md/<job_uuid>")
5. ssh_write_file("~/praxis-md/<uuid>/input.pdb", structure_bytes)
6. (metadynamics) ssh_write_file("~/praxis-md/<uuid>/input.plumed", plumed_bytes)
7. sbatch_script = render_sbatch(sim_type, params, work_dir, account)  # str
8. ssh_write_file("~/praxis-md/<uuid>/job.sh", sbatch_script.encode())
9. ssh_run("sbatch ~/praxis-md/<uuid>/job.sh")  # 输出 "Submitted batch job 12345"
10. parse slurm_job_id 从 stdout
11. MdJobRepo.update_submitted(id, slurm_job_id)
12. return 200 {id, status: 'queued'}
```

### 6.2 Poll worker 流程(backend startup)

```
async def poll_loop():
  while True:
    sleep 30s
    active = MdJobRepo.list_active()  // status IN (queued, running)
    if not active: continue
    slurm_ids = [j.slurm_job_id for j in active]
    # 一次 squeue 拉所有
    squeue_out = ssh_run(.53, f"squeue -j {','.join(slurm_ids)} -o '%i|%T|%R'")
    parse → still_active_set
    for job in active:
      if job.slurm_job_id in still_active_set:
        new_status = parse_state(squeue line)   // queued/running
        if new_status != job.status:
          MdJobRepo.update_status(job.id, new_status)
          if new_status == 'running' and not job.gpu_host:
            MdJobRepo.update_gpu_host(job.id, parse_node(line))
      else:
        # 已离队列 → sacct 查终态
        sacct_out = ssh_run(.53, f"sacct -j {job.slurm_job_id} -o State,CPUTimeRAW,Elapsed,...")
        parse → terminal_state, cpu_h, gpu_h (gpu_h 估算自 elapsed × ngpu)
        cost = compute_md_cost_li(gpu_h, cpu_h, free_cpu_h, p_gpu, p_cpu)
        async with conn.transaction():
          MdJobRepo.finalize(id, status=terminal_state, cpu_h, gpu_h, cost_li=cost)
          if cost > 0:
            ledger.record(conn, user_id, -cost, kind='md_consume', ref_type='md_job', ref_id=id, meta={'gpu_h':..., 'cpu_h':...})
```

**sacct State → schema status map**:

| sacct State | schema status |
|---|---|
| `COMPLETED` | `done` |
| `FAILED`, `NODE_FAIL`, `OUT_OF_MEMORY`, `BOOT_FAIL` | `failed` |
| `CANCELLED`, `CANCELLED+` | `cancelled` |
| `TIMEOUT` | `failed`(error 字段记 "slurm_timeout") |
| `RUNNING`, `PENDING` | 不应出现(squeue 已捕),若出现 → log + 跳过本次,下轮再查 |
| 其他 / 拿不到 | `failed`(error 记 sacct 原文)|

### 6.3 Cancel 流程

```
POST /api/md/jobs/{id}/cancel
1. handler 检 auth + ownership(or admin)
2. 拿 row → 若 status ∉ (queued, running) → 409 not_active
3. ssh.ssh_run(.53, f"scancel {slurm_job_id}")
4. MdJobRepo.update_cancelled(id)
5. return 200 {ok: true}
```

下次 poll worker scan 时,squeue 不会有该 job → sacct 拿到 CANCELLED 状态。**cancel 时不扣费(同 spawn carry 决策)。**

### 6.4 GPU Pool 流程

```
GET /api/md/gpu-pool
1. auth 检
2. ssh.ssh_run(.53, "~/check_gpus.sh") → JSON 串
   {hosts:[bio0000XX...], gpus:[{host, gpu_id, name, mem_mb, util_pct, busy, busy_label}], total_slots, busy_slots, free_slots}
3. return 200 <JSON>
```

`check_gpus.sh` (`.53` 上部署,完整脚本见 `scripts/check_gpus.sh`,M11.2 D5 ship):

```bash
#!/usr/bin/env bash
# 顺序 ssh 到 GPU 节点拉 nvidia-smi,聚合为 JSON。
# 若 .53 装了 pdsh,可改 parallel 版,但顺序版无外部依赖更稳。
set -euo pipefail
NODES=("${PRAXIS_GPU_NODES[@]:-bio000071 bio000072 bio000073 bio000074}")
python3 - "${NODES[@]}" <<'PY'
import json, subprocess, sys
nodes = sys.argv[1:]
gpus, hosts_busy = [], {}
for h in nodes:
    try:
        out = subprocess.check_output(
            ["ssh", "-o", "ConnectTimeout=5", "-o", "BatchMode=yes", h,
             "nvidia-smi --query-gpu=index,name,memory.used,memory.total,"
             "utilization.gpu --format=csv,noheader,nounits"],
            text=True, timeout=15,
        )
    except subprocess.SubprocessError as e:
        # node 不可达:标全 8 卡 busy_label=unreachable
        for i in range(8):
            gpus.append({"host":h,"gpu_id":i,"name":"?","mem_mb":"0/0","util_pct":0,
                         "busy":True,"busy_label":"unreachable"})
        continue
    for line in out.strip().splitlines():
        idx, name, mem_used, mem_total, util = [s.strip() for s in line.split(",")]
        busy = int(util) > 5 or int(mem_used) > 500   # 阈值粗筛
        gpus.append({"host":h,"gpu_id":int(idx),"name":name,
                     "mem_mb":f"{mem_used}/{mem_total}","util_pct":int(util),
                     "busy":busy,"busy_label":None if not busy else "in_use"})
busy = sum(1 for g in gpus if g["busy"])
print(json.dumps({"total_slots":len(gpus),"busy_slots":busy,
                  "free_slots":len(gpus)-busy,
                  "hosts":nodes,"gpus":gpus}))
PY
```

## 7. 错误处理

| 场景 | 处理 |
|------|------|
| FE 提 sim_type 不在白名单 | 400 `{error: "unsupported_sim_type"}` |
| sim_params 缺必填(smd 缺 pull_rate) | 400 `{error: "missing_sim_param", field: "pull_rate"}` |
| structure file_id 不存在或非本 user | 404 `{error: "structure_file_not_found"}` |
| balance ≤ 0 | 402 `{error: "insufficient_balance"}` |
| active job ≥ 2 | 429 `{error: "too_many_active", active, limit}` |
| ssh 连接失败 / sbatch 命令失败 | 502 `{error: "hpc_unreachable", reason}`(M11.2 不 retry,M11 carry 加) |
| poll worker 异常 | log + continue;不阻塞 loop |
| sacct 拿不到终态(job 失踪) | status='failed' + error="sacct: not_found" |

## 11. 已知 carry → M11.x / v0.13.x

1. **进程 crash → stale running**:backend 重启后 active jobs 失去 poll worker 跟踪。startup hook 需要 reconcile(同 spawn carry)
2. **umbrella / remd**:dispatch_strategy + parent_id + N children sbatch 编排,v0.13.1
3. **FE MdModal 扩展**:smd pull 表单 / plumed picker
4. **artifacts SSH-cat 流下载**:M10 storage 远程接通
5. **auto-retry on 429 / preemption**:同 spawn M11 carry
6. **WHAM 后处理 / replex demux**:跟 umbrella/remd 同 ship
7. **progress 精度**:目前仅 elapsed/expected,可换 mdrun log 解析
8. **`.53` 上 work_dir 清理**:`~/praxis-md/<uuid>/`(input/job.sh/输出)长期累积。MVP 不清,M11.x carry 加 cron 或 finalize 时 mv 到归档目录
