# Versioning

**PRAXIS-VirtualCell 1.0.0** starts the standalone product release series.
This product version is declared in `pyproject.toml` and mirrored by the CLI,
API, browser interface, and software citation metadata. Earlier 1.6.0 and 1.7.0
records describe the pre-standalone development history; they do not continue
this product's release numbering.

Data schemas, model and adapter contracts, environment identities, and evidence
artifacts retain their own versions. Starting the standalone product series does
not renumber existing scientific artifacts or change their recorded validation
status. These identities remain part of execution provenance.

A software release does not promote a model's scientific or product status.
Compatibility and validation gates apply to the exact recorded artifact scope.
Public schema changes must document compatibility or provide a migration path.
