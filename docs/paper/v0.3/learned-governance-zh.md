# 可学习的可靠性治理：从基于规则到可学习、运行时生效的选择性可靠性

*本文是论文《面向可信虚拟细胞扰动预测的脑引导多智能体运行时》（PRAXIS-VirtualCell v0.2）的 v0.3 增补章节。本章扩展 v0.2 的"结果"部分，不修改 v0.2 正文。文中脚注式引用编号沿用 v0.2 的参考文献表（完整条目见文末）。*

## 范围与阅读指引

v0.2 已经确立：为虚拟细胞扰动预测提供拒识、弃权、溯源与可审计能力的，是一套治理**运行时**，而非更强的预测器；并且 v0.2 用的是**基于规则**的治理——硬性门控会拒绝不支持的物种、空靶点、整体被拒的集成、以及核心预测器失败，外加一个基于"分歧阈值"的弃权规则，并给出正向的风险–覆盖曲线（v0.2 §3.4）。本章报告下一步工作：一个**可学习**的可靠性层，用来处理规则无法处理的**软风险**；它被冻结为不可变的 artifact 并作为默认模式接入运行时；我们以诚实的方式，将其与规则基线以及若干单信号启发式进行对照评估。

全文有三个**承重**的区分，我们靠**构造**而非靠**声明**来保证它们彼此分离：

1. **泛化 vs. 运行时集成。** 可学习模型的*泛化能力*只用扰动级的留扰动交叉验证（OOF/CV）来评估（见 §A、R2、R3）。规则 vs. 可学习的运行时对照（R7）是一次**样本内（in-sample）集成回放**——冻结模型是在全部 151 条 ledger 上拟合的，对照又在同一批 151 条上回放——因此我们严格地把它读作"可学习层确实改变了运行时决策，并保住了硬规则与溯源"的证据，**而不是**独立的泛化基准。
2. **扰动级 vs. 单细胞级。** 本章的每一个数字都是在评估 ledger 上的**扰动级**选择性可靠性行为（以每扰动的 Δ-Pearson 作为可靠性目标）。它们都**不是** v0.2 的招牌**单细胞级** Δ-Pearson（0.7039）。我们绝不声称可学习治理改善了单细胞级预测准确率；它改善的是扰动级的选择性可靠性决策。
3. **可学习软治理 vs. 硬规则门控。** 硬性失效（不支持的物种、空靶点、所有预测器被拒、核心失败，以及本章新增的：artifact 缺失/被篡改/schema 不匹配）由规则与 fail-closed 默认值治理。可学习层只治理*软*决策（在预测器适用的前提下，这个扰动是否足够可靠到可以作答、降级、还是弃权）。可学习层从不覆盖硬规则。

这是 PRAXIS-VirtualCell 治理线在其自身口径下的工作。另一个平行问题——可学习治理是否能推广到其它智能体场景（例如对 LLM 智能体做代码门控）——不在本章范围内，本研究未对其评估（见"讨论"）。

## A. 证据分层（请先读此节）

为了避免把样本内集成回放误读成泛化结果，我们给每一条定量结论标注它属于哪一类证据：

| 证据类型 | 它证明了什么 | 招牌数字 | 如何产生 |
|---|---|---|---|
| **泛化（OOF/CV）** | 可学习模型并非只是记住训练 ledger；在未见折的扰动上，它对可靠性的排序优于单信号启发式。 | bad-扰动检测 AUROC **0.907**；弃权风险–覆盖 AUC **0.746**；可靠性回归 OOF 相关 **0.701** | 扰动级留扰动 5 折交叉验证；每折模型只在训练折上拟合、对留出折打分（`reliability_model.cv_reliability`）。 |
| **运行时集成（样本内回放）** | 冻结并接入运行时后，默认模式相对规则确实改变了软风险决策，同时硬规则与溯源完好无损。 | wrong-accept **0.974 → 0.211**；risk-coverage **0.026 → 0.789**；hard-rule-override **0**；溯源**完整** | 冻结的生产模型（在全部 151 条上拟合）在同一批 151 条上回放（`mode_compare.compare`）。按构造即为样本内。 |
| **安全 / 溯源** | 可学习打分不会泄漏标签；artifact 缺失/被改时降级回规则；每个决策都可追溯到不可变的 artifact 哈希。 | 防泄漏断言；artifact 缺失/schema/不全/篡改时 fail-closed 回退；每个决策带 `artifact_sha256` | 编译期特征/标签分离；内容哈希自校验；fail-closed 加载器；7 道集成 gate。 |

泛化由 OOF 那几行承载。运行时那一行是集成测试。我们不在这几行之间做平均，也不把样本内回放的数字当作样本外性能来呈现。

## 结果

### R1. 规则挡住硬性失效，但软可靠性风险需要一个可学习信号

v0.2 的规则门控是必要的，我们予以保留：它们能挡住范畴性失效（不支持的物种、空靶点、整体被拒的集成、核心失败）。但它们在*软*风险上很弱——即预测器虽适用、但答案很可能不可靠的那类扰动。v0.2 的弃权用的是单一手设规则（集成的成对余弦分歧超过固定阈值 0.5）。

有两项发现支持"去学习这个软信号"而非"手设"它。其一，在 M1 评估 ledger 上，每扰动的分歧分数是准确度的真实且强力的预测因子：corr(分歧, 每扰动 Δ-Pearson) = **−0.716**（n = 60）；高分歧的那一半平均 Δ-Pearson 为 **0.571**，而低分歧的那一半为 **0.841**——在预测器彼此分歧的扰动上，准确度大约低 27 个点。其二，没有任何单一基预测器处处最优：在 151 个扰动上，最准的预测器是 GNN 75 次、线性模型 39 次、隐变量模型 37 次。分歧信号是真实的，可靠性在扰动间是异质的——这正是一个可学习可靠性头能够胜过单一固定阈值的情形。

### R2. 可学习的可靠性模型胜过单信号启发式（OOF 泛化）

我们训练了一个刻意做轻的可靠性模型——一个纯 Python 的岭回归（ridge），输入三个推理期可得的特征（集成分歧、一个分布外标志 `seen_in_train`、以及一个零向量对计数）——用来回归每扰动的可靠性目标（Δ-Pearson），并标记落在底部四分位的"bad"扰动（bad 阈值 Δ-Pearson 0.455；151 条中 38 bad / 113 good）。评估采用扰动级留扰动 5 折交叉验证、用留出折（OOF）预测，并做了防泄漏控制：特征抽取器在编译期断言任何标签列（Δ-Pearson、每预测器 Δ-Pearson、best-predictor）都不能进入特征矩阵。

| bad-扰动检测器（OOF） | AUROC |
|---|---|
| **可学习（分歧 + OOD + 零向量对）** | **0.907** |
| 仅 OOD | 0.788 |
| 仅分歧（v0.2 用的信号） | 0.774 |
| 随机 | 0.479 |

可学习模型对可靠性目标的回归 OOF 相关为 **0.701**。学习一个三特征组合，使 bad-扰动检测相对于已经驱动了 v0.2 的强力"仅分歧"启发式提升了 **+0.13 AUROC**。因为这些是留出折预测，所以这是泛化结果，不是记忆。

### R3. 可学习弃权压过基于规则的弃权（OOF；升级 v0.2 表 C）

我们把 OOF 可靠性预测转化为一个选择性预测（弃权）策略，并测量风险–覆盖——对每个排序信号，先在最不可靠的扰动上弃权，并跟踪覆盖率下降时保留集的准确度。v0.2 表 C 用分歧来排序；这里用可学习可靠性来排序。

| 弃权排序信号 | 风险–覆盖 AUC |
|---|---|
| oracle（真 Δ-Pearson；上界） | 0.7822 |
| **可学习（可靠性 OOF）** | **0.7460** |
| 仅 OOD | 0.7297 |
| 仅分歧（v0.2） | 0.7196 |
| 随机 | 0.6595 |

在覆盖率 1.0 / 0.8 / 0.6 时的保留集 Δ-Pearson，可学习为 0.657 / 0.733 / 0.796，而仅分歧为 0.657 / 0.713 / 0.749：在 60% 覆盖率下，可学习策略相对 v0.2 规则多保留 **+0.047** 的 Δ-Pearson，捕获了约一半的"规则→oracle"差距。选择性可靠性决策现在是可学习的、并严格优于 v0.2 的手设规则，同时仍明显低于 oracle 上界（我们报告该上界以避免过度宣称）。

### R4. 加入预测幅度/不确定性特征没有帮助——一个负结果

在确定模型之前，我们测试了更丰富的推理特征是否有帮助。我们为全部 151 个扰动计算了每预测器的预测-delta 范数（幅度）与每预测器的标准差（不确定性），并重跑同样的 OOF 交叉验证。

| 特征集 | 回归相关 | bad-扰动 AUROC | 风险-覆盖 AUC |
|---|---|---|---|
| **base（3：分歧 + OOD + 零向量对）** | **0.701** | **0.907** | **0.7460** |
| base + 6 个原始（范数/标准差 × 3 预测器） | 0.686 | 0.891 | 0.7378 |
| base + 2 个派生（范数离散 + 平均标准差） | 0.699 | 0.905 | 0.7450 |

6 个原始特征*降低*了每一项指标（在 151 个样本上引入噪声 / 轻度过拟合）；2 个派生特征则持平。因此我们**不**加入它们：模型保持其三个 base 特征。这强化了核心论点——模型间分歧（余弦）是主导的可靠性信号，与 R1 的 −0.716 一致，而原始预测幅度/不确定性在当前数据规模下不带来正交增益。报告负结果是对"特征驱动型过拟合"的一道防线；该结论被明确限定在当前 151 扰动 ledger 与三个 donor-stack 预测器的范围内，待 ledger 扩大或接入更异构的预测器后应重测。

### R5. 冻结 artifact 接入运行时（默认 `learned_with_rule_fallback`）

可学习层不是旁路分析：它就是运行时默认。我们把全量拟合的模型冻结为不可变、可复现的 artifact——`reliability_model_v0_3.json`（特征 = 分歧 / `seen_in_train` / 零向量对；标准化岭回归权重：分歧 **−0.118**、`seen_in_train` **+0.136**、零向量对 **0**；外加训练 ledger 的 sha256 与 `n_train` = 151）、`abstain_head_v0_3.json`（预测 Δ-Pearson 低于 0.448 弃权、低于 0.549 降级；记录的风险-覆盖 AUC 0.746）、以及 `feature_schema_v0_3.json`（模型特征与禁用标签列表）。`ReliabilityAgent` 新增 `mode` 参数；工作流默认注入 `reliability_mode = learned_with_rule_fallback`。端到端地，报告会带上可学习决策（例如模式 `learned_with_rule_fallback`、可靠性分数 0.717、版本 `reliability_v0.3.0`）。

关键在于，硬规则在每种模式下都保持规则权威：物种/空/整体被拒/核心 这些决策由规则门控做出，可学习层只接管*软*的降级/软弃权决策。一个单元测试（`test_hard_abstain_not_overridden_by_learned`）独立确认：当可学习模式激活时，硬弃权不会被覆盖。

### R6. Fail-closed 且可审计

可学习打分器在构造上是安全的：

- **无泄漏。** 运行时打分器会断言推理特征字典中不含任何标签键（`delta_pearson`、`per_predictor_delta_pearson`、`best_predictor`）；标签进入运行时特征会触发异常，而非悄悄打分。
- **Fail-closed 回退。** artifact 缺失、特征 schema 版本不匹配、必需字段不全、或内容哈希不匹配（我们对模型的 features/mean/std/weights/lam 重算一个 `content_sha256` 并比对）——以上任一情形都返回 `fallback=True`，调用方回退到规则路径。因此篡改冻结权重会把系统降级回规则，而不是执行一个被改动过的模型。
- **可审计。** 每个可学习决策都带 `artifact_sha256`（以及弃权头的哈希）、`model_version`、`feature_schema_version`、`features_used`、以及 `fallback` 标志，因此每个软决策都可追溯到产生它的那个确切的不可变 artifact。

7 道集成 gate 覆盖了这些行为（模型可运行；artifact 缺失 → 规则；schema 不匹配 → 规则；标签进特征 → 断言；报告含可学习决策；风险-覆盖 AUC 0.746 可从 ledger 复现；硬弃权不被覆盖），并与完整的 Mac 测试套件一同运行。

### R7. 规则 vs. 可学习，正面对照——一次运行时集成回放（不是泛化基准）

最后，我们问：把默认从 rule-only 切到 `learned_with_rule_fallback`，是否真的改变了运行时的软风险决策。我们让 151 条 ledger 通过两种模式回放（真实分歧、真实 Δ-Pearson 标签；bad = 底部四分位，阈值 0.455；38 bad / 113 good）。

| 模式 | wrong-accept ↓ | unnecessary-abstain ↓ | risk-coverage ↑ | retained-utility ↑ | flag 数 | hard-rule-override | 溯源 |
|---|---|---|---|---|---|---|---|
| rule-only | **0.974** | 0.018 | **0.026** | 0.982 | 3 | 0 | — |
| **learned_with_rule_fallback** | **0.211** | 0.195 | **0.789** | 0.805 | 52 | **0** | **完整** |

rule-only 几乎不触及软风险：它只在分歧超过 0.5 时才 flag，但大多数 ledger 扰动落在 0.5 以下，于是它只 flag 了 151 条中的 3 条，接受了 97.4% 的 bad 扰动（risk-coverage 0.026）。可学习默认则 flag 了 52 条，抓住了 79% 的 bad 扰动（wrong-accept 0.974 → **0.211**，risk-coverage 0.026 → **0.789**），代价是更多的不必要弃权（0.018 → 0.195）与更低的保留效用（0.982 → 0.805）——一个合理的风险/可用性折中。可学习模式下 hard-rule-override 为 **0**、溯源**完整**。

> 因为该对照回放的是被用来冻结与审计治理 artifact 的那同一批扰动 ledger——而且冻结模型正是在这 151 条全部之上拟合的——我们把它解读为一次运行时集成与决策行为测试，**而非**独立的泛化基准。泛化由扰动级留出折的可靠性（R2）与弃权（R3）分析单独评估。rule-only 一臂在此表现差，主要是因为其固定的 0.5 阈值偏保守、而 ledger 分歧大多在其之下；可学习一臂从*同一个*特征里提取出了更多决策信号。

收窄到最稳的表述：在可学习默认下，运行时把规则放过的软可靠性风险重新抓了回来，同时保住了硬规则权威与完整可审计性。

## 方法（简）

**防泄漏的特征与划分。** `governance/ledger_features.py` 把每个 ledger 列归为三类：推理特征（预测时可得）、标签（真实准确度，禁止当特征）、诊断（规则决策本身，仅作基线）。`extract_features` 在编译期断言 特征 ∩ 标签 = ∅；`leave_perturbation_out_folds(k=5)` 以"一条目 = 一个扰动"划分，给出扰动级划分、无 cell 泄漏。

**可学习模型。** `governance/reliability_model.py` 是一个纯 Python 的标准化岭回归（不依赖 numpy/sklearn），作为适配 151 样本的轻模型而选定。`cv_reliability` 产生用于全部泛化数字（R2、R3）的 OOF 预测；`fit_full` 产生供运行时冻结用的全量拟合参数（R5、R7）。`governance/abstain_head.py` 把 OOF 可靠性转成风险–覆盖曲线。

**冻结与运行时。** `governance/freeze_artifacts.py` 导出带训练 ledger 哈希与版本的 artifact（可复现）。`governance/learned_reliability.py` 加载它们、断言无泄漏、自校验内容哈希、fail-closed、并返回带溯源的打分决策。`governance/mode_compare.py` 运行 R7 的样本内回放。

**对照的诚实性。** R7 使用全量拟合的冻结模型、在其自身的训练 ledger 上回放；R2/R3 使用留出折预测。二者作为不同的证据类型呈现（§A），从不合并。

## 局限

- **扰动级，非单细胞级。** 所有数字（约 0.5–0.9 的 Δ-Pearson、AUROC、风险-覆盖）都是评估 ledger 上的扰动级选择性可靠性统计；它们不是、也不可与 v0.2 的单细胞级招牌数（0.7039）比较。
- **R7 按构造为样本内。** 规则 vs. 可学习的表回放的是冻结模型据以拟合的同一批 151 条。它展示的是决策行为的改变与硬规则/溯源的保全，而非样本外性能；泛化的主张落在 R2/R3。
- **单一对照（W4.5）。** 分歧目前是相对单一基线计算的，而非完整的单细胞级对照；−0.716 及下游信号是在该单对照设定下成立的，预期改用单细胞级对照后会更锐利。
- **小样本，无置信区间。** ledger 为 151 个扰动、单一确定性 5 折；我们未报告 bootstrap 置信区间。跨折 OOF 的差距（0.907 vs 0.774；0.746 vs 0.720）很清晰但没有区间；对招牌数字做扰动级 bootstrap CI 是一项干净的、已计划的强化。
- **三个特征。** 可学习模型用三个推理特征；在当前规模下更丰富的特征没有帮助（R4），但该结论被限定在当前 ledger 与预测器集合内。
- **运行时 `seen_in_train` 多为 None。** 训练集查表尚未接入运行时，故 `seen_in_train` 通常缺失，`predict_dp` 用训练均值填补（在 `features_used` 中如实记录）；分歧是主导特征，故影响有限。
- **阈值非端到端调优。** 弃权/降级阈值由训练预测分位数（15% / 35%）设定，而非端到端优化；`unnecessary-abstain` 会随阈值移动。
- **ledger 中无硬规则触发样本。** ledger 全为 human / 词表内的软决策样本，故 R7 中的 `hard_rule_override = 0` 按构造成立；硬规则的保全由单元测试独立证明，而非由该表证明。
- **预测性能不胜 SOTA。** 基预测器为 donor-stack 变体；在同一划分上的强外部专用基线（例如 GEARS / scGen / STATE）是未来工作，且不影响本章的可学习治理主张。

## 讨论

PRAXIS-VirtualCell 的可靠性治理从基于规则推进到可学习：一个轻量、防泄漏的可靠性模型，其泛化优于驱动了 v0.2 的单信号分歧启发式（bad-扰动 AUROC 0.907 vs 0.774；弃权风险–覆盖 AUC 0.746 vs 0.720，均为留出折），并且一旦冻结并作为默认接入，它就可度量地把规则放过的软可靠性风险抓了回来（运行时回放中 wrong-accept 0.974 → 0.211），同时保住硬规则权威、fail-closed 安全性、以及逐决策的可审计性。这锐化了 v0.2 的论点：适用性与弃权应作为被强制执行的控制流进入流水线[13][14][15][16][17]，而这套控制流本身可以是*被学习*的，且无需放弃硬性保证——是对"面向科学的可信 AI"[21]与可复现性[22]立场的一个延伸，而预测核心仍是离线且确定性的。同样的可学习治理范式（在异构预测器之上的一个冻结、可审计、fail-closed 的可靠性头）大概率可推广到其它智能体场景，例如对 LLM 智能体做代码门控，但我们在此不予评估、也不对此作任何主张。
