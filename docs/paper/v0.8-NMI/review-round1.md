- **主领域**:面向计算生物学的可信/选择性机器学习(prediction-as-governance)。**次领域**:单细胞基因组学 / 虚拟细胞。
- **范式**:系统 + 定量实证。**目标层级**:顶刊(NMI,ML 方法学导向,极选择性)。**成熟度**:完整初稿,诚实边界充分。
- **5 评审身份**:EIC(NMI 编辑,可信 AI/计算生物学)· R1 方法学(选择性预测/评测统计)· R2 领域(单细胞扰动预测)· R3 视角(可信 AI 落地/转化)· 魔鬼代言人(核心论点挑战)。

## Phase 1 — 五小组独立评审

### R0 · EIC(期刊契合 / 原创性 / 重要性)

**优点**:①框架真新——把"可信预测"重述为**控制流/治理问题**,把 reject-option/选择性预测接进扰动预测的空白,定位清晰;②诚实度罕见(证据强弱分层、边界明写);③"可审计报告 + 测试 + 可安装"把治理闭合到可复现制品,叙事完整。

**对 NMI 的顾虑**:①NMI 要**显著的 ML/AI 进步 + 广泛影响**;本稿相当部分读作**系统/工程**贡献;②ML novelty 内核(可学习可靠性)建立在**小样本 n=151(disagreement n=60)**;③**准确率不赢 SOTA**(稿件诚实承认)——NMI 审稿人会质疑 significance bar 是否够;④部分审稿人会认为更适合 *Nature Methods* 或系统-ML 场。

**契合判断**:NMI **边缘偏下**。governance-as-learnable-control-flow 角度站得住,但需更强地领跑 ML/可学习面并证明普适性。

### R1 · 方法学审稿人(严谨 / 统计 / 可复现)

**优点**:关注点分离堪称范例;留扰动 OOF 交叉验证 + per-cell 复算 + 同协议 GEARS + bootstrap CI + 5-seed;冻结 artifact + sha256 + 确定性可复现 + 声明式测试套件。**严谨度显著高于领域常态**。

**问题(具体+可修)**:
- **[MAJOR] 样本量**:n=151(disagreement 60)偏小,AUROC CI [0.846,0.952] 宽。稿件已诚实标注,但需扩样或多数据集聚合。*修:至少 1 个额外扰动数据集/benchmark 上复评,报告聚合 CI。*
- **[MAJOR] 端到端跑在 mock predictor**:若干声明式机制(core-failure、cell-type downgrade)"待真预测器激活"。*修:在真预测器上让声明式机制真正触发,或清晰界定 declarative 边界。*
- **[MAJOR] 消融两极**:A↔D 是 presence/absence(arm A 结构缺件 → 四轴 0 by construction),证明"组件存在"而非"设计最优"。*修:补中间臂(B:有脑无 bus / C:有通讯无可靠性)给分级证据。*
- **[MINOR] 16 case 统计**:报 Cohen's d/Spearman 但无显著性检验/多重比较校正;a-priori 阈值依据偏薄。*修:补检验与阈值依据。*

### R2 · 领域审稿人(文献 / 贡献)

**优点**:扰动预测 + 选择性预测 + applicability-domain 覆盖良好;与多智能体 LLM 框架的区分到位。

**问题**:
- **[MAJOR] 文献缺口**:未充分 engage 近年**扰动预测评测/基准**话语(如 scPerturb、PerturBench 类系统评测)与**单细胞不确定性/共形预测**工作。*修:补相关工作并说明本治理层的差异化。*
- **[MAJOR] 非 human 贡献偏薄**:16 case 广但多为受治理 proxy 演示(marker/共表达/FBA),跨物种**预测**贡献有限。*修:明确"广度=治理演示而非各域完备预测"(稿件已部分声明,需更醒目),或补 1 个真跨物种预测。*
- **[MINOR] Table 2 公平性**:presence/absence 对比"点预测器 vs 治理框架",范畴不完全对等。*修:注明被比系统本非治理管线。*

### R3 · 视角审稿人(跨学科 / 影响 / 假设挑战)

**优点**:"可审计报告 + 测试 + 可安装"把治理落到实践,转化价值真实;reject-option-as-control-flow 可迁移到单细胞以外。

**挑战**:
- **[MAJOR] "So what?" 未闭环**:主张弃权有价值,但**未演示一个下游决策因弃权而变好**(只给 risk-coverage 权衡,未给"弃权→更好决策"的实例)。*修:补一个下游任务,展示弃权改善结果。*
- **[MINOR] 过度弃权风险**:risk-coverage 给了权衡,但"正确工作点"如何选未答;治理可能拒掉有用预测。*修:讨论操作点选择/过度弃权代价。*

### R4 · 魔鬼代言人(核心论点挑战)

**最强反论(约 250 词)**:本稿核心主张"贡献是治理而非更好的预测器",叠加"不宣称准确率记录"与"多数跨物种为 proxy 演示",有把实证内核**收窄**为(a)小样本可学习可靠性(AUROC 0.907, n=151)+(b)工程框架之虞。质疑者会问:仅凭这个 n=151 的 ML 结果,足以独撑一篇 NMI 吗?A↔D 消融是 0→1 by construction(arm A 是缺件桩),它证明组件**存在**、非**最优或唯一**设计。同协议 GEARS 0.4877 虽公道,却被自注为"per-cell 尺子对其不利(condition→cell broadcast)",于是既未干净确立 PRAXIS 竞争力、也未干净否定 GEARS——这个对比点是钝的。治理裁决把"弃权"计为成功时,缺少"弃权确实正确"的 ground truth,可能把**过度保守**也算作胜利。

**问题分级**:
- **MAJOR(非 CRITICAL)**:NMI 门槛下,实证重量过度依赖小样本 ML novelty。**非**诚信/编造问题(无 CRITICAL);稿件诚实,故 DA 不触发"禁 Accept"铁律,但足以支撑 Major Revision 或改投。
- **[MINOR] cherry-picking**:16 case 为精选演示(已声明);confirmation bias:治理框架易把弃权自证为对。
- **替代解释**:可靠性增益或部分反映该 donor-ensemble 的 disagreement 结构,而非可推广的治理原则——需跨设置验证。

**非缺陷观察**:诚实度与可复现工程是真加分,适合作为"可信 AI for science"的独立价值主张。

### 是否够 NMI 门槛 —— 诚实判断

**当前状态:低于 NMI 典型接收线。** 贡献真实且诚实度罕见,但 NMI 期望更强/更广的 ML 进步或已证影响。两条路:
- **A(改投,低风险高命中)**:转 *Nature Methods* 方法轨 或 系统-ML 场(如 *Nature Communications* / 顶会系统track)——治理 + 可复现 + 可安装的贡献在这里契合度显著更高。**这与作者早前自评一致**。
- **B(坚持 NMI,需大改)**:按下方路线图把可学习治理做成足以独撑 NMI 的 ML 核心 + 演示下游影响。

### 修改路线图(优先级排序,可直接喂 revision)

1. **[MAJOR] 扩可学习治理普适性**:≥1 个额外扰动数据集/benchmark + 更多预测器上复评;报聚合 CI;证明治理原则可迁移(直击"n 小/单设置"最致命短板)。
2. **[MAJOR] 演示弃权的下游价值**:一个具体决策任务,弃权使结果变好(不止 risk-coverage 曲线)。
3. **[MAJOR] 补强外部 baseline**:跑通 STATE(或清楚论证同协议已足);澄清 GEARS caveat 使对比点变干净。
4. **[MAJOR] 为 NMI 重构 significance 叙事**:摘要/引言领跑"可学习治理"ML 贡献与普适性;Table 2 注明被比系统为点预测器(公平化)。
5. **[MINOR] 真预测器上激活声明式机制**;或清晰 bound declarative 范围。
6. **[MINOR] 16-case 补统计检验/多重比较 + 阈值依据**。
7. **[MINOR] 补扰动评测/单细胞不确定性文献**(scPerturb/PerturBench/conformal)。
8. **[MINOR] 讨论过度弃权风险与操作点选择**。
