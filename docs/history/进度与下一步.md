## 一、这是个什么项目

简单说,PRAXIS-2 = **一个跑在自己服务器上的"科研版 Claude"**。
你给它发一句"帮我分析这份冷冻电镜数据",它会:

1. 先去**"大脑"**(`brains/` 里 12 个学科的知识库)里检索 → 拿到背景
2. 按**纪律**(RMCP:检索优先 → 计划 → 执行 → 收尾)一步步推进
3. 调**工具/技能**(轻量代码在本机跑,重活如 GPU 训练投到 HPC 超算)
4. 通过**SSE 流**实时把过程吐回前端给你看
5. 全程**记得登录的人是谁**,各人的会话/余额/审核都隔离

整个内核是从头用 Python 重写的,不是套别人的框架。

## 二、已经完成了什么(按里程碑)

每个里程碑都有 git tag,失败可以 `git checkout v0.X` 回到任何中间状态。

### M0 — 脚手架(tag `v0.0`)
**人话**:打地基。
配置文件、上游 LLM 客户端(连 Anthropic Claude)、存储抽象、确定性测试框架(用 cassette 录制 API 响应,不用真烧 token 也能跑测试)。

### M1 — 内核闭环(tag `v0.1`)
**人话**:让 AI 能调用工具,跑个最简单的多轮对话。
比如用户问"现在几点",AI 调 `get_time` 工具,拿到结果,回答你。处理了断网/超时/中止等异常。

### M2 — Prompt 单一路径(tag `v0.2`)
**人话**:**所有发给 AI 的提示词只走一条管子**。
之前如果有多条路径拼提示词,改一处忘改另一处就会出 bug。M2 把这件事强制做成单一路径,还能用 `--dump-prompts` 把每次发出去的提示词存下来调试。

### M3 — 权限 + RMCP(tag `v0.3`)
**人话**:**让 AI 守科研规矩**。
RMCP 是一套相位机:必须先 retrieve(检索文献)→ 再 anti_filter(反向过滤)→ 再 plan(计划)→ 再 execute(执行)→ 最后 seal(收尾)。AI 还没检索就想跑实验?权限层直接拒。也内置了 DOI 必须真存在、必须有证据链等硬规则。

### M4 — 记忆 / 会话 / 压缩(tag `v0.4`)
**人话**:**对话能续上,上下文不爆**。
- 记忆三层:全局 / 项目 / 用户
- 会话能存盘 → resume(中断后从断点恢复,工具调用对齐)
- 上下文超长时自动压缩(API 摘要 / 工具结果裁剪 / pinned 重注),不破坏 API 闭环

### M5 — 技能 / 智能体 / 大脑(tag `v0.5`)
**人话**:**5 种角色 + 12 个学科库 + 可装的技能**。
- agent 模式:`one-above-all`(总指挥) / `general`(通用) / `<学科>`(专科) / `yourself` / `bare`(裸模式)
- 大脑:`brains/cell|crispr|cryo|dock|drug|enzyme|immuno|md|microbiome|omics|pharma|protein`,12 学科 613 个文档已真灌入
- 技能(SKILL.md):YAML 头解析、渐进披露(只把当前需要的 1% 占预算)、依赖探测、in-process 执行器
- 审核闭环:学习到的新经验先进 review 队列 → 管理员审核 → 通过后晋升到对应 `brain:<slug>` + 热加载

### M6 — Web / 并发 / 可观测(tag `v0.6`)
**人话**:**变成多人能用的 Web 服务**。
- 纯 ASGI server(没有 FastAPI 重依赖)
- 多 worker / 多租户:每个用户互不干扰
- SSE 13 种消息全集(text_delta / tool_use / tool_result / final / error / ...)
- 跨 worker pub/sub:不同 worker 的会话事件能在前端一致看到
- 远程权限桥:AI 要做敏感操作 → ASK → 前端弹窗 → 用户点是/否,超时自动 deny
- 管理员审核面板 API + observability 统一面板 + DriftMonitor(模型行为漂移监测)

### M7 — 调度 / HPC / 压测(tag `v0.7`)

## 六、最容易踩的坑(给小白)

1. **跑测试要在 venv 里**:`. .venv/bin/activate` 后再 `pytest`,否则找不到包
2. **macOS 的 `._*` 文件**:Finder/iCloud 同步会生成 AppleDouble,M5 已修,但偶尔 rsync 还会带过去 → `--exclude '._*'`
3. **`PRAXIS_ANTHROPIC_API_KEY` 必填**:`config.py` fail-fast,缺即 `ConfigError`,服务起不来
4. **`.gitignore` 已含 `hpc_submit_account.toml`**:真账号永远不要 push
5. **审查 / 测试 / commit 顺序**:**改代码 → 跑 pytest 全绿 → 跑 ruff check 净 → commit**,顺序不能颠倒
6. **总纲 vs 代码冲突**:**先改总纲再改代码**(D3 原则,M0–M9 全这样)
