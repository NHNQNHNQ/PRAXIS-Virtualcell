# 数据许可与来源

主项目原始代码采用 MIT；此许可不替代第三方实验数据或外部模型许可。

- ChEMBL 来源记录标注 CC BY-SA 3.0。AB 组件保留 molecule/assay/document 关联和清洗记录；数据再分发需保留来源及许可，不能把其声明成 MIT 数据。
- PubChem 获取记录标注 public data；具体来源与获取记录随本地数据保留。
- SyntheMol-MCTS v1.0.3 作者代码为 MIT，下载清单中的模型/数据资产为 CC BY 4.0，Zenodo DOI 为 `10.5281/zenodo.13932150`。本目录的源固定和校验信息见 `integrations/synthemol/`。
- Abaucin 原始论文附件、本地基因组和大规模原件保持本地；本次未确认其全部独立再分发条件，因此不随 GitHub 代码上传。

大数据源的论文、版本、字段和实验条件保持在相应来源记录中。已发表或可下载不等于可以省略 attribution。
