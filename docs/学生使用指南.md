## 1. 这是什么

**PRAXIS Suite** = 生物医药 AI 助手集合。你问问题,后台真实的 LLM(大语言模型)会调用对应学科的"专家大脑"和工具,给出有依据、可执行的回答。和普通 ChatGPT 的区别:

- **13 个学科专家**(细胞、CRISPR、蛋白结构、分子动力学、药物设计、组学、微生物组……),每个学科都挂着真实的知识库(case + rule + 工作流)
- **3 种对话模式**:`ask`(对话答疑)、`plan`(出可执行方案)、`auto`(plan + 自动后台跑长任务)
- **诚实**:不会瞎编数据。没做过的实验、没跑过的工具,它会说不知道或者告诉你怎么做

**用途**:作为本课程的研究工具——让 AI 帮你查文献、设计实验、分析数据、做结构预测,完成你的研究作业。

## 4. 三种对话模式(关键)

输入框右下角的下拉(默认 💬 ask),决定 AI 怎么回答你:

| 模式 | 适用 | 输出 |
|---|---|---|
| 💬 **ask** | 问答、解释概念、查文献、讨论思路 | 直接的答复,可能多轮 |
| 📝 **plan** | 要 AI 给你一个**可执行方案**(实验设计、计算流程) | 结构化的 SPEC(YAML),写明步骤、参数、依赖 |
| ⚡ **auto** | 同 plan,但 AI 写完 SPEC 后**自动后台开跑** | 立即返回任务 ID,你可以去做别的;点🪐图标查后台任务 |

**新手建议:先用 ask 摸清问题,等清楚了再切 plan 让它出方案。⚡ auto 只在你确认要真跑、能等几分钟到几小时时用**(会消耗较多余额)。

## 6. 完成研究作业的推荐工作流

这是核心。建议按这 5 步推进你的研究:

### Step 1 — 选题:用 🌐 通用助手 或 🧠 一统大脑 探索方向(💬 ask 模式)

```
例:我想研究 BCR-ABL1 T315I 突变对 imatinib 结合的影响,
   有哪些可行的研究路径?需要哪些数据/工具?
```

AI 会给你:相关 case、需要的实验/计算步骤、潜在难点。**不要急着深入,先聊 2-3 轮把范围搞清楚**。

### Step 2 — 锁定方向:切到对应学科 agent,深入读知识库(💬 ask 模式)

```
例(在 🧷 Protein agent):
   T315I 突变的结构基础是什么?有哪些已发表的结构?
   哪些预测工具能给出可靠的突变体结构?
```

学科 agent 挂着真实的 case/rule/工作流知识库,会引用具体文献和方法。

### Step 3 — 出可执行方案:切 📝 plan 模式

```
例(在 🔗 Dock agent):
   给我一个完整 SPEC:用 AutoDock Vina 把 imatinib 对接到
   BCR-ABL1 T315I 的预测结构,要哪些输入文件、参数、输出指标
```

AI 会写一份 YAML SPEC——这是**可以拿去真跑或者按图给老师/助教看**的方案。

### Step 4 — 真跑(可选):切 ⚡ auto 模式 或 老师协助跑

- 简单计算(如某些 Pharma 药代数值 / Immuno MHC 预测 / Protein 部分预测)系统**真的能跑**,⚡ auto 会自动后台执行,完成后回到原对话提示你
- 大计算(MD 动力学、Cryo-EM 重构、大型 Dock 库)staging 环境**可能不能跑**——这时 plan 模式给出的 SPEC 就是你的"研究方案",拿到实验室跑或者按方案分析公开数据

### Step 5 — 整理输出:导出关键对话

- 每个对话右侧三个按钮:📝(Markdown)/🌐(HTML)/📥(JSON)
- 导出 Markdown 直接拿来写报告 / 附录
- 一次研究作业建议至少导出:① 选题对话 ② 方案 SPEC ③ 关键讨论

## 7. 用得更好的几个技巧

**多轮对话**:直接接着问就行,AI 会承接上文。同一对话里追问比"重新开一个"更省余额、更准。

```
你: 米氏方程中 Km 和 Vmax 分别是什么?
AI: ...
你: 那 kcat 呢?和上面的关系?       ← 直接追问,会承接
```

**上传文件**:📎 按钮(或拖拽进输入框)。可以上传 PDF 文献、PDB 结构、CSV 数据等让 AI 帮你看。

**换底座模型**:输入框底部下拉,默认 `deepseek-v4-pro`,可换 `aws-gpt-5.4`。复杂任务两个都试试看哪个回答好。

**慢一点是正常的**:深度问题需要 **30-90 秒**——AI 在后台真的在调工具、读知识库。不要刷新页面,等就行。

**console 看到红字别慌**:登录前 401 是正常的(浏览器先试探鉴权)。其他报错截图给老师/助教。

## 10. 常见问题

**Q:登录后侧栏没东西?**
A:正常。新账号没有历史对话,点 **+ 新对话** 开始即可。

**Q:发了消息一直转圈?**
A:复杂问题 30-90 秒正常。**不要刷新**。超过 2 分钟仍无回应,关掉对话重发一次。

**Q:AI 说"我没真的跑这个工具"?**
A:正常诚实声明。说明该工具在 staging 环境跑不了。**plan 模式给出的 SPEC 是你的方案**,拿去线下/实验室跑。

**Q:误删了对话怎么办?**
A:右侧侧栏点 × 是删除,**不能撤销**。重要对话**先导出再删**。

**Q:账号被同学占了?**
A:找老师调换一个空的账号。

**Q:网页打不开?**
A:确认在校园网或者 VPN 里,直接访问 `http://10.102.106.40:8080`(`http://`,不是 `https://`)。

## 附录 B:研究作业示例(优先选这些,**便宜、可控、有产出**)

> ⚠️ **省钱原则**:绝大多数研究作业**只用 💬 ask + 偶尔 📝 plan 就够**。**不要轻易开 ⚡ auto**(会自动跑后台计算,容易把余额烧光)。下面 5 个方向都是「问答 + 方案设计 + 知识整合」型,预估花费都在 **¥0.1–¥0.5 之间**(¥10 余额做 20+ 次完整作业都用不完)。

### 示例 1 — 文献综述型(💬 ask · **最便宜**,约 ¥0.05–0.2)

选一个具体小话题,用 ask 模式深挖 4-6 轮,最后整理成 1500-3000 字综述。

**操作模板**(任选一个学科,以 🧬 CRISPR 为例):
1. 🧬 CRISPR + 💬 ask:"近 5 年 prime editing 在临床前研究的进展,关键技术突破是什么?"
2. 接着追问:"几个代表性团队/系统(PE2/PE3/PEmax)的差异和适用场景"
3. 追问:"目前还没解决的关键瓶颈?"
4. 追问:"和 base editing、HDR 相比,prime editing 的优劣边界?"
5. 最后:"帮我把以上对话整理成一个综述大纲,3 级标题 + 关键文献的引用提示"
6. 📝 MD 导出 → 写报告

**适合学科**:全部 13 个。换关键词即可(microbiome 用 "人肠道菌 16S 标准化流程的争议";enzyme 用 "工业酶 thermostability 工程化的代表性策略")。

---

### 示例 2 — 概念辨析 / 方法对比(💬 ask · **便宜**,约 ¥0.05–0.15)

挑一个有争议的方法学问题,让 AI 把不同方案的**真实差异**说清楚——既能学知识又能直接写进报告。

**操作模板**:
1. 🧷 Protein + 💬 ask:"ESMFold、AlphaFold2、AlphaFold3、Boltz 这四个结构预测工具,**真实差异**是什么(不要套话,从训练数据、推理速度、置信度估计、复合物支持四个维度对比)"
2. 追问:"在我这个场景下应该选哪个?(场景描述:[xxx])"
3. 追问:"如果我同时跑两个工具,结果不一致怎么判断哪个可信?"
4. 📝 MD 导出

**其他可选**:
- 🦠 Microbiome:"DADA2 vs QIIME2 vs USEARCH 在 16S 分析中的差异"
- 📊 Omics:"scanpy vs Seurat 在 scRNA-seq 工作流的差异"
- 💊 Drug:"REINVENT vs GA-based 生成方法在 hit-to-lead 阶段的取舍"

---

### 示例 3 — 实验方案设计 + 评估(💬 ask + 📝 plan · **中等**,约 ¥0.1–0.3)

让 AI 出方案,你**评估这个方案**——这是**最有学术价值**的作业类型(锻炼批判性思维)。

**操作模板**(以 🧪 Enzyme 为例):
1. 🧪 Enzyme + 💬 ask:"我想改造 [某个酶,如 PETase] 提高其在 60°C 的活性,有哪几条主流路径?"
2. 🧪 Enzyme + 📝 plan:"出一份完整 SPEC:基于 [某条路径,如 directed evolution + computational design]改造 PETase,包括起点、每轮工作量、评估指标、终止条件"
3. 切回 💬 ask:"上面这个方案,有哪些**潜在风险**?哪一步最容易卡住?"
4. 追问:"如果我没法做湿实验,这个方案的哪些步骤可以**纯计算**完成?"
5. 📝 MD 导出方案 + 评估,写"方案 + 我的批判性分析"报告

---

### 示例 4 — 公开数据解读(💬 ask · **便宜**,约 ¥0.05–0.2)

不用自己跑实验/计算,**找一个公开的结构/数据集让 AI 帮你读懂**。

**操作模板**(以 🔗 Dock 为例):
1. 🔗 Dock + 💬 ask:"PDB ID 6LU7(SARS-CoV-2 Mpro 与 N3 抑制剂的复合物)结构里,**结合关键**在哪些残基?N3 怎么放进口袋的?"
2. 追问:"如果我想设计一个新抑制剂,这个结构告诉我什么 SAR(构效关系)?"
3. 追问:"为什么这个口袋很难成药/为什么 N3 不能直接做药?"
4. 📝 MD 导出 → 写"基于公开结构的设计思路"报告

**其他可选**:
- 🧷 Protein:挑一个 PDB ID 让 AI 解读折叠/功能
- 🦠 Microbiome:"分析下 HMP(人类微生物组计划)数据集的代表性发现,争议在哪"
- 💉 Pharma:"atorvastatin 的 FDA 不良事件报告里反映出什么 PK/PD 问题"

---

### 示例 5 — 跨学科整合 mini 综述(🧠 一统大脑 / 🎭 自由模式 + 💬 ask · **便宜**,约 ¥0.1–0.3)

不挑学科,用智囊模式让 AI **自己路由**,做一个跨学科话题的小综述。

**操作模板**:
1. 🧠 一统大脑 + 💬 ask:"我想理解 T 细胞激活的完整链路:从 TCR-MHC 识别 → 信号通路 → 转录组变化 → 表型分化。这条链路上各环节的研究方法分别属于什么学科?"
2. AI 会跨学科回答(涉及 🛡 Immuno、🧫 Cell、📊 Omics)。继续追问:"信号通路这块,目前最有争议的点?"
3. 追问:"组学这块,scRNA-seq 在这个问题上有哪些代表性发现?"
4. 切到 🎭 自由模式 + 💬 ask:"把上面的链路画成一个**关键节点图**(文字描述也行),每个节点标注:① 主要分子 ② 主流研究方法 ③ 代表性争议"
5. 📝 MD 导出
