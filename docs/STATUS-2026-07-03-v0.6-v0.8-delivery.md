## 4. 关键发现与修复(排查揭露的既存问题)

1. **CI 双红(既存,非本次引入)**:origin/main 的 CI 在 ruff(563 lint 错)和 pytest(14 个继承 PRAXIS-2 md/files 陈旧 mock 单测)两步都长期红。经核对 origin/main 干净态确认非本次改动导致 → 先做 CI 转绿切片扫清,后续每步 push 才能保持绿。
2. **打包 gap(真实缺陷)**:`pyproject` 的 `packages.find` 原只打 `praxis2`,构建的 wheel **不含 `praxis_virtualcell`/`praxis_vc_api`**——`praxis-vc` CLI 会 ImportError。已修:`packages.find` 增补两包 + `include-package-data` + `MANIFEST.in`(纳 catalogs/brains/governance 运行时数据,`global-exclude ._*` 防 macOS AppleDouble 污染 wheel)。
3. **诚实边界**:未为"路由层拒绝不存在的基因"编造测试(该校验在下游 GEM 层,cobra-gated);negative 只固化实际存在的拒绝行为。
