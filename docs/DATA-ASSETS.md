# 数据与模型

| 本地位置 | 内容 | 边界 |
| --- | --- | --- |
| `data/organisms/AB5075-AZI000/` | 3,895 个 ABUW 基因的未给药历史表达参考及参考注释 | 作者 log2 TPM QC 尺度、两个源样本的历史条件均值；不是新分离株的当前状态 |
| `data/organisms/_sources/` | 首个组学包的六项原始资料、来源记录 | 单份实体存储，归档路径链接到此处；完整历史响应数组不向 LLM 暴露 |
| `data/mdr_gnb/` | EC 27,175 结构 MIC、774 肽、AMR 数据、129 个模型与来源/划分/GEM | 127 个模型为已知药物 AMR 分类；结构活性不随指定菌株背景变化 |
| `data/antibacterial/abaumannii/` | 12,349 条 MIC、5,807 结构母体、来源关联和四套 v3 划分 | 8,671 条菌株标签未解析；物种为 A. baumannii |
| `models/abaumannii/direct_mic/` | 2026-09-13 本地交付包中的 12 个权重 | seeds 17/42/2026；不是 09-23 比较中的 314159 权重 |
| `data/antibacterial/abaumannii/` 内生长筛选 | ATCC17978 8,404 条实验记录，161 阳性 | 原始库与旧模型预选记录需分层 |
| `candidates/` | 两次相同种子生成的 24 个候选及记录 | 运行复现，尚非实验确认的抗菌候选 |
| `research/mdr_gnb/mic_discovery/` | 菌株基因组/MIC 关联候选和探索工件 | 未完成资格核验，不作为生产联合预测标签 |

所有大型数据和模型保持本地，Git 忽略其路径。公开结果的实验范围、旧版本和失败应与原来源一并保留。

迁移后的主项目是已保留数据的实体存放位置。`PRAXIS-virtualcell-old/` 中的重复数据路径通过相对符号链接或交付包成员引用清单指向它们，避免再保存一份；不同版本、未迁入的原始资料继续保留在归档。具体布局见 [迁移与恢复](CONSOLIDATION.md)。

当前推理只加载明确的菌株/条件组学包；上述历史 MIC、AMR 模型和生成分数不作为候选预测输入。首个组学包的来源、未知值和导入能力见 [OMICS](OMICS.md)。

旧 MIC 数据的菌株、单位与实验条件解析尚未完成。后续若用于独立评估或训练，仍需先核验，不能据此宣称当前 LLM 的准确率。
