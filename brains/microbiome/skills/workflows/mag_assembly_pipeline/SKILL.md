# mag_assembly_pipeline

## Purpose
Reconstruct draft genomes from shotgun metagenomic reads via the modern (2026) consensus pipeline. Implements rule-03 (multi-binner + DAS_Tool) and rule-10 (Hi-C augments not replaces).

## Sanity baseline (mock metagenome)
Reference: 5-genome mock metagenome generated by wgsim (1M reads × 5 known genomes).
- Pass: ≥4 high-quality MAGs (>90% completeness, <5% contamination) recovered AND GTDB-tk taxonomy matches input genomes at species level for ≥3.

## Usage
```bash
python -m skills.workflows.mag_assembly_pipeline.run \
    --reads-dir /home/zkyd/data2/mzy/PRAXIS-Microbiome/runs/task-003/host_removed \
    --out-subpath runs/task-003/mag_out
```
