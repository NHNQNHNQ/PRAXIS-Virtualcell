# 01 构建默认路线

## 核心规则

收到构建任务后，先按体系类型选择默认路线，不要一开始就混用多条工具链。

## 默认路线

- 水溶液蛋白体系：默认走本地 `gmx` 路线。
- 细胞膜体系：默认用 `PACKMOL-Memgen` 生成膜环境，再进入本地 `GROMACS`。
- 小分子参数化：默认用本地 `AmberTools`，不依赖网页界面。

## 适用

- 普通蛋白水盒
- 膜蛋白体系
- 蛋白-配体复合物
- 跨膜小分子体系

## 为什么

- 水溶液体系最稳定、最适合作为基线。
- `PACKMOL-Memgen` 更适合稳定生成细胞膜环境。
- `AmberTools` 更适合自动化、批处理和本地可复现参数化。
