# 02 力场与构建前检查

## 核心规则

开始正式构建前，先确认力场目录、参数来源和输入质量；不要等到 `mdrun` 报错时才回头补检查。

## 必查项

- 使用 `CHARMM36` 时，必须显式指定力场目录位置，例如工作目录下的 `./charmm36-feb2026_cgenff-5.0.ff`。
- 混合力场前，先检查小分子原子质量和 `atomtypes` 区块。
- 如果小分子来自 `AmberTools` 或其他自动参数化流程，先验证数值和 include 顺序，再运行 `grompp`。

## 适用

- 本地 `gmx pdb2gmx`
- `CHARMM36 + GAFF2`
- 蛋白-配体体系
- 跨膜小分子体系

## 为什么

- 力场目录不明确时，容易混用系统默认目录和项目目录。
- 质量错误会直接导致能量爆炸，重复 `atomtypes` 会导致 `Invalid order`。
