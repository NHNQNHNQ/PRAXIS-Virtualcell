# 07 分析前置处理与 PBC 完整性

## 核心规则

做结构分析前，先确认轨迹已经过合适的 PBC 处理；不要把未校正轨迹直接拿去做 `RMSD`、`RMSF`、`Rg`、氢键或距离分析。

## 必查项

- 优先确认是否已经做过 `gmx trjconv -pbc mol -center` 或等价处理。
- 如果 `RMSD` 出现异常大跳变，先怀疑 PBC 伪影，再讨论真实构象突变或解离。
- 蛋白-DNA、蛋白-配体和跨膜体系都要先检查轨迹是否适合分析。

## 适用

- `RMSD`
- `RMSF`
- `Rg`
- `H-bond`
- 最小距离和界面接触
- 蛋白-DNA 复合物
- 蛋白-配体复合物

## 为什么

- PBC 伪影会把本来连续的轨迹切碎，导致结构分析数值失真。
- 先修正轨迹，再做解释，能避免把技术伪影误判成生物学事件。
