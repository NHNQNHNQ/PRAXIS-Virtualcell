# 03 体系验收与膜体系 fallback

## 核心规则

真正的体系验收标准是 `gmx grompp` 能生成 `tpr`；如果膜体系在整体系路径上持续失败，就切换到稳定 fallback，而不是继续硬修输入。

## 验收标准

- 不要把“已经有 `gro` 和 `top`”当作构建成功。
- 只有 `gmx grompp` 通过，才说明拓扑、坐标、索引和参数至少在当前阶段自洽。

## 膜体系 fallback

- 如果蛋白加整膜混合体系在 `CHARMM36` 下直接 `pdb2gmx` 或 `grompp` 持续失败，应切换到“蛋白拓扑和单脂质拓扑分开生成，再重组总体系”的路线。
- 如果膜体系准备进入 `NVT` 或 `NPT`，推荐先重建只保留 `Protein`、`Membrane`、`Water_and_ions` 的干净 `index`。

## 适用

- 水溶液体系
- 膜蛋白体系
- 混合力场体系
- `Unknown cmap torsion`
- `tc-grps` 报错排查

## 为什么

- `grompp` 通过才代表体系真的可进入下一阶段。
- 整体系失败常常是边界解析问题，不是力场模板缺失。
- 脏组、重复组或覆盖不全会直接导致温控组错误。
