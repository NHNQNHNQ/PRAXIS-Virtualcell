- 从目前保留下来的结果证据看，Agent 最终没有将结果部分扩展成难以自洽的大而全分析，而是收敛为一条更稳健的证据链：终点几何读出、异构通路残基组成，以及通路接触在变化组与对照组之间的前后差异。这一取舍本身就说明 Agent 并非只是“生成更多图”，而是在复杂课题中做了结果压缩与证据优选。
- 在 8B8Q 体系中，Agent 最终保留的终点读出是 I515-K616 的距离。结果显示，PS 条件下该距离整体变小，提示终点口袋更偏向收紧或局部重排后的状态。与此同时，异构通路中的酸性网络以及口袋壁残基接触出现了系统性重排，说明变化不仅是终点局部噪音，而是存在从上游网络向终点口袋传递的协同结构变化。
- 在 8XEJ 体系中，Agent 将链 B 的 W45-I152 距离确定为最终终点口袋读出。结果显示，切割体系中这一距离明显增大，支持 close-like 到 open-like 的终点几何变化。进一步的接触变化分析表明，用户指定的通路残基集合内部发生了“上游收紧、终点打开”的重构模式，其中中段某些接触增强，而靠近终点口袋的关键接触减弱。这种“局部打开”与终点距离增大相互支持，使得结果具有更强的机制解释力。
