# Advisory module gene sets

These three small mappings were authored for PRAXIS-VirtualCell as qualitative
routing aids. They are informed by public GO/Reactome biological concepts but
are not exports or official subsets from either database. The mappings are
covered by the repository MIT license.

They may only activate evidence-limited M1/M5/M8 advisory modules. They do not
provide measurements, effect sizes, or numerical predictions.
