# Contributing

Install the development profile and run the focused tests in [docs/TESTING.md](docs/TESTING.md). Preserve original experimental conditions, data relations, source IDs and model versions. Keep measured outcomes, model predictions and mechanism hypotheses separate.

Do not commit API credentials, server recovery records or large local model/data artifacts. Changes to scientific behavior require validation against the relevant frozen task; directory or documentation changes do not qualify a model scientifically.
