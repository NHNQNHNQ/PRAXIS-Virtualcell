# MDR-GNB MIC 研究资产

本目录从 PRAXIS-MDR-GNB 合并而来，保存 MIC、菌株身份、基因组关联的数据探索和方法代码。

- 顶层 `mic_*.py` 为可复用研究辅助模块，导入路径为 `research.mdr_gnb`。
- `mic_discovery/` 保存原始下载、派生表、基因组/GFF3、输入清单和历史验证记录。它们仍属于探索资产，尚不能作为新化合物对特定菌株的经过验证的预测器。
- `mic_discovery/**/derived/*.py` 与旁边的原始 SHA 文件按历史版本保存，部分脚本包含旧项目绝对路径或前置授权记录。复现前需显式选择输入和新输出目录；本次整合未执行数据检索、重训或重算，也未改变这些原始记录。
- 大型数据留在本地，不随 GitHub 源码提交。正式预测入口是 `praxis_virtualcell.mdr_gnb`。
