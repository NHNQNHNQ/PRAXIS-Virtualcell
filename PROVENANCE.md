# Project provenance

PRAXIS-VirtualCell 1.0.0 is the standalone distribution of the VirtualCell
scientific runtime in `praxis_virtualcell`, its experiment agents, CLI, local
API, and browser applications. Biological inputs, scientific protocols,
recorded evidence, and the corresponding software tests accompany that runtime.

Earlier development included PRAXIS-2 agent tooling. That general-purpose
implementation is outside this standalone distribution. Existing source
attribution remains in the retained license notices; starting a separate product
release series does not change the origin of previously developed source.

For the scientific description, see Zhenyu Ma and Xukai Jiang,
[PRAXIS-VirtualCell: A Programmable and Trustworthy Framework for Agentic Virtual Cell Experiments](https://arxiv.org/abs/2609.29221v1),
arXiv:2609.29221v1 (2026), DOI: 10.48550/arXiv.2609.29221.
Citation metadata is provided in [CITATION.cff](CITATION.cff) and
[CITATION.bib](CITATION.bib).

Software version 1.0.0 identifies this product release. Data, model, adapter, and
evidence versions remain separate scientific identities; recorded benchmark
scores, abstentions, and validation limits retain their original scope.
